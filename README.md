# Assistente Demo – Trattoria Il Tortellino d'Oro

Demo di un assistente virtuale (chatbot) per ristoranti e piccole attività: risponde a orari, menù, prezzi e allergeni e raccoglie prenotazioni inviandole al titolare via WhatsApp.

- Italiano (predefinito): `index.html` oppure `?lang=it`
- Spagnolo: `?lang=es`

Sito statico, nessuna chiave o dato privato. Personalizzabile modificando `config-it.js`.
